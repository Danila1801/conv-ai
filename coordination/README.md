# coordination/

Working notes between the three of us and the Claude sessions of Goktug and Dan. The sessions cannot see each other's chats, so they talk through these files.

| File | What it is for |
| --- | --- |
| `STATUS.md` | The current state: board of work packages, what is in progress, what waits on a person, requests, decisions |
| `LOG.md` | One short entry per working session: done, checked, not checked, next |
| `AI-USAGE.md` | One line per session on what Claude did. We write the AI-use statement in the notebook from this |

## How to use it

- Starting a session (person or Claude): read `STATUS.md`, then the newest entries of `LOG.md`.
- Ending a session: update your rows in `STATUS.md`, add a `LOG.md` entry, add a line to `AI-USAGE.md`. Commit them together with the work.
- Antonia does not need to write in `LOG.md`. A message in the group chat is fine, and whoever reads it updates `STATUS.md`.

## The hand-in copy

This folder is for working. It is not part of what we hand in. When we make the clean repo at the end, we leave out `coordination/`, `CLAUDE.md`, `research/raw/`, `course/` and `.claude/`. (`course/` holds the teachers' slides and papers, which are not ours to publish.) The AI-use statement in the notebook stays, and it has to match `AI-USAGE.md`.
